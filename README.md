# Mixed Code Samples Repository

This repository contains a collection of code snippets, examples, and learning exercises taken from multiple projects and topics.  
Each file demonstrates specific concepts, languages, or frameworks, and serves as a reference or training material.

---

## 📂 Contents & Descriptions

### 1. **Daily Schedule HTML**
- **File:** `daily-schedule.html`
- **Description:**  
  A simple HTML page displaying a daily schedule in a table format.  
  Demonstrates:
  - HTML table structure
  - Basic `<th>` and `<td>` usage
  - Border styling using the `border` attribute

---

### 2. **Tech News Links HTML**
- **File:** `tech-news-links.html`
- **Description:**  
  A minimal HTML page with clickable links to popular technology news websites.  
  Demonstrates:
  - `<a>` anchor tag usage
  - External hyperlinks with full URLs

---

### 3. **C# Access Modifiers Example**
- **File:** `AccessmodifierKeyWord.cs`
- **Description:**  
  A C# class demonstrating **access modifiers** in object-oriented programming.  
  Explains:
  - `public`, `private`, `protected`, and `internal`
  - Accessibility scope for each modifier
  - Example usage of fields and class-level visibility

---

### 4. **Blazor Layout Template**
- **File:** `MainLayout.razor`
- **Description:**  
  A Blazor WebAssembly layout component that defines the page structure for an online shop or dashboard.  
  Demonstrates:
  - Sidebar navigation (`NavMenu`)
  - Top navigation row
  - Main content rendering with `@Body`
  - Integration with Bootstrap 5

---

### 5. **React Learning Plan (NERD Approach)**
- **File:** `react-learning-plan.md`
- **Description:**  
  A comprehensive step-by-step learning roadmap for mastering React, designed using the **NERD** (Note, Example, Reason, Do) approach.  
  Includes:
  - Core concepts (JSX, components, props, state, hooks)
  - Project-based learning path
  - Suggested resources and exercises
